## Background/Related Works

## Metrics
**Energy Distance**
Statistical distance between two probability distributions
$$\mathcal E(X,Y)=2\Bbb E[||X-Y||_2]-\Bbb E[||X-X'||_2]-\Bbb E[||Y-Y'||_2]$$
where $X,X'\sim \Bbb P$ and $Y, Y'\sim\Bbb Q$ are independent random vectors
- penalizes the model if the predicted cells are far from the true cells, subtracting the internal spread of the distributions

**Maximum Mean Discrepancy**
$$MMD^2(\Bbb P, \Bbb Q)=\Bbb E_{x,x'}[k(x,x')]+\Bbb E_{y,y'}[k(y,y')]-2\Bbb E_{x,y}[k(x,y)]$$
Using specifically Gaussian (RBF) kernel:
$$k(x,y)=\exp\left(-\frac{||x-y||^2_2}{2\sigma^2}\right)$$
- bandwidth $\sigma$ set dynamically
- RBF kernel gives MMD a localized view of manifold, sensitive to higher-order moments

**Mean Squared Error of Means**
standard pseudobulk metric, calculates MSE between average predicted cell and average ground-truth cell
$$MSE=||\mu_{\text{pred}}-\mu_{\text{true}}||^2_2$$
**Wasserstein Distance**
$$\mathcal W_2(\Bbb P, \Bbb Q)=\left(\underset{\pi\in \Pi(\Bbb P, \Bbb Q)}\inf\int||x-y||^2_2d\pi(x,y)\right)$$
Where $\Pi(\Bbb P, \Bbb Q)$ is the set of all joint distributions with marginals $\Bbb P$ and $\Bbb Q$




## Losses
**NBReconLoss**
- treats decoder as a parameter generate for a negative binomial distribution
- predicts $\mu$ mean expression and $\theta$ dispersion
- calculates the negative log-likelihood
- minimizing the NLL maximizes prob that raw counts came from the NB distribution defined by the latent code $z$

**PullbackIsotropyLoss**
computes pullback metric (metric tensor $G$)
- weights genes by importance in the NB manifold
- use JVP instead of calculating Jacobian matrix to see how output changes in the direction of each latent basis vector
- forces $G$ to look like scaled identity matrix ($\alpha I$), which enforces the latent space is isometric

**DistancePreservationLoss**
Ensures global structure is preserved
- takes pairwise distances in high-dimensional space and forces the euclidean distances between latent points to match them

**FlowMatchingMSELoss**
Standard loss for Optimal Transport Conditional Flow Matching (OT-CFM)
- trains vector field to predict the velocity required to move a cell from its control state towards its perturbed state
- minimizes difference between predicted velocity and ideal straight line velocity in the latent space

**OTLoss**
uses EMD to compare distribution of predicted cells at $t=1$ to the distribution of observed perturbed cells

**DensityLoss**
uses k-Nearest hinge loss to penalize model if it generates cells far away from any real observed cells
- bad for generating off manifold, like unseen effects, i.e. higher dosage than seen, drug not seen before, etc.

**EnergyLoss**
- penalizes the square of the velocity along the integrated path

Encoder does lookup -> project -> concatenate -> compress

Let $\mathcal B$ be the condition batch containing $p$, the primary perturbation index, $\mathcal K=\{k_1,k_2,\dots, k_n\}$, a set of perturbation-specific covariate indices (covariates could be of different types, like drug, dose, etc. for a single cell), and $\mathcal S=\{s_1, s_2,\dots, s_m\}$, a set of sample-specific covariate indices (again, could be of different types, like replicate 1, cell type A, well 3). 

First, we retrieve a learned dense embedding and pass it through a non-linear projection $f_{\text{proj}}$. For the perturbation, $z_p=\sigma(W_p\cdot \text{Emb}(p)+b_p)$. For the perturbation covariates: $z_{k,i}=\sigma(W_{k,i}\cdot \text{Emb}(k_i)+b_{k,i})$ for $i\in \{1,\dots,n\}$. For the sample covariates: $z_{s,j}=\sigma(W_{s,j}\cdot \text{Emb}(s_j)+b_{s,j})$.

The final output of the encoder is the result of passing the concatenation of the projections through the final output MLP ($g_\phi$). 

$$E_\phi(\mathcal B)=g_\phi([z_p\oplus z_{k,1}\oplus\dots \oplus z_{k,n}\oplus \dots \oplus z_{s,m}])$$

Since we use the same number of covariates for all cells in an experiment, and each cell can only have one covariate for each type (cell can't have multiple cell types, same is true for all covariates we are dealing with), $g_\phi$ is a fixed size, we also ensure consistent ordering of covariates, i.e., perturbation always first.

## related_work.md

# CPA
- compositional perturbation autoencoder
- learns to predict perturbation response for unseen dosages, cell types, time points, and species
- enables incorporating the chemical representation of the drugs to allow for prediction for completely unseen drugs
- brute-force exploration of the combinatorial search space is infeasible
- mechanistic models are good for interpretations but require longitudinal data and don't scale well to genome-wide measurements
- current DL models at the time only model a small set of perturbations, can't handle combinations, and cant incorporate continuous covariates like dose and time or discrete covariates like cell type, species, patient
- CPA learns factorized latent representations of both perturbations and covariates
- CPA decomposes the scRNA-seq data into a collection of embeddings associated with covariates
- using an adversarial loss, it forces the embeddings to be independent of each other, which allows for recombining them at prediction time to predict the effect of novel perturbation-covariate combinations
- this also would work for the underrepresented context generalization task
- CPA can guide experimental design by directing hypotheses towards expression patterns of interest to experimentalists
- the goal of CPA is to factorize the latent space to turn them into interpretable and compositional models
- gene expression latent spaces are non-linear so we can't describe observed gene expression as a factor model, which would map each component in the latent space to a single perturbation
- each cell is labeled with covariates as categorical labels or continuous values
- learned drug-response curve
- CPA uses encoder neural network to decompose gene expression for a cell into learnable, additive embeddings, corresponding to the basal state, observed perturbations, and observed covariates
- latent representation CPA encoder learns about basal state is disentangled from the embeddings corresponding to the covariates and perturbations
	- this is done by training a discriminator classifier (adversarial network)
- CPA learns to reconstruct combinatorial treatment effects by linearly combining singleton treatment embeddings and a basal state and feeding that to the decoder
- chemCPA introces a perturbation network that encodes small molecules using known chemical descriptors, which replaces the perturbation embedding dictionary in CPA

# CellFlow
- generates prediction in latent space (PCA or VAE)
- generated cells are decoded to gene space (log1p-transformed and normalized) -> allows to compute metrics in gene space
- metrics are computed in latent space, typically PCA space between 10 and 100 dims, which is different than the PCA space that CellFlow was trained on, if it's trained in PCA space, that will be PCA from the training data only, whereas the PCA for metrics is calculated from the whole dataset
- generative models for images are typically evaluated by the Wasserstein distance between true and predicted images in the latent space of the Inceptionv3 model
- for each condition, compute 50 top DEG and compute R squared for those
- use optimal transport to pair unperturbed and perturbed cells
	- no growth or death
- encorporates pretrained embeddings of biological entities
	- use molecular fingerprints for small molecules and ESM2 embeddings for protein products of gene knockouts and proteins
- does flow matching in the latent space (PCA or VAE)
- aggregates covariate encodings and applies MLP to get to single condition embedding
- integrates ODE using neural network to predict instantaneous velocity from $t=0$ to $t=1$ for prediction
	- conditions velocity network on condition embedding $c$, position $X_t$ and time $t$, so predicted velocity is $v_\theta(c, X_t, t)$
- Need to encode combinations of treatments in permutation-invariant manner to model multiple interventions at the same time
	- CellFlow uses two set aggregation schemas, MHA and deep sets
		- deepsets are functions $f(X)$ operating on a set of items $X=\{x_1,\dots x_m\}$ that can be decomposed into the following structure: $f(X)=\rho(\text{Aggr}(\{\phi(x_i\mid x_i \in X\})$
			- $\phi$ is element-wise transform, typically MLP, applied to each element in the set
			- $\text{Aggr}$ is an aggregation function, where order does not matter
			- $\rho$ is a global transformation, like a neural network 
- optimal transport is done batch-wise
- CellFlow shows that on the sciPlex3 dataset, all methods show comparable performance at low dosages, none outperform the baseline
	- because low dosage have no significant effects or more subtle effects (lower edistance between control distribution and perturbed distribution)
- found PCA to be better for distributional metrics and VAE better for mean gene expression

# MIOFlow
- uses geodesic autoencoder embedding
- define approx of diffusion ground distance from samples that they call diffusion geodesic distance
- autoencoder is regularized to match the distance
- train geodesic autoencoder to minimize difference between l-2 distance in autoencoder latent space between two points and diffusion geodesic distance between the two points
- local method only predicts next sample (timepoint, predict $\hat{X}_{t+1}$ given $X_t$) whereas global predicts entire trajectory given initial condition $X_0$
- loss on marginals is used in both local and global cases, is W_2 distance between predicted and observed distributions, summed over marginal
- energy loss is summed over marginals, squared l_2 norm of model output (velocity) integrated from this marginal to the next
- density loss encourages trajectories to stay on the manifold
	- loss is distance to k-nearest neighbors in $X_t$ given a lower bound $h\gt 0$ (hinge loss?)
- add diffusion term to trajectories to model diffusion, results in an SDE
- very good performance and good speed up over other models in W_1, MMD(G), MMD(M), and runtime
	- test is leaving one timepoint out
- also good performance on embryoid body dataset

# GAGA
- train an autoencoder to lean latent space where euclidean distances match manifold distances in the ambient space
- derive a warped metric on the dataspace to produce a pullback Riemannian metric on the data manifold with large distances for points off the manifold
	- enables computation of on-manifold geodesics for data generation
- autoencoder jointly optimizes reconstruction loss and local distance matching loss
- sample points from distributions for training, use OT coupling with ground distance as euclidean distance in latent space, this OT plan minimizes total geodesic length because of how autoencoder is trained with distance loss
- generate geodesics by integrating the vector field
- vastly improved performance on trajectory inference in PCA space for Cite and Multi datasets, leave one timepoint out, W_1 distances

## Cflows
- adds granger causality to infer state transitions and gene regulatory interactions
- updates MIOflow to BEMIOflow, adding a network that predicts growth rate of a cell continuously in time to model cell growth and death, augments the optimal transport
- perform trajectory training in PHATE space
- embeds gene expression data into PHATE space by first doing PCA and then training an encoder network regularized by PHATE distances

# FlatVI
- regularizes the latent manifold of discrete likelihood variational autoencoders towards Euclidean geometry
- enhances compatibility with downstream approaches that assume Euclidean latent geometry
- building linear latent trajectories assuming the latent space is Euclidean is not optimal when this assumption is violated, as the straight line paths through latent space do not necessarily correspond to geodesic paths on the manifold induced by the decoder
- regularizes the pullback metric of the decoder to make straight paths in latent space correspond to geodesic interpolations along the manifold of the decoded space
- focus on statistical manifolds
	- points on a statistical manifold are probability distributions of a pre-defined family
- when you train a VAE as a likelihood model, the VAE's decoder image maps latent codes to a statistical manifold's parameter space
- in scRNA-seq data, individual gene counts are assumed to follow a negative binomial distribution
- FlatVI regularizes the latent space through a flattenting loss, which pushes the pullback metric from the stochastic VAE decoder to be a scaled idenitity matrix everywhere (same scale everywhere)
- Fisher Information Metric (FIM) is the natural metric tensor of a statistical manifold
	- FIM defines the local geometry of the statistical manifold
	- can be used to build the pullback metric for arbitrary decoders
- If $M(z)=\Bbb I_d$, then the geodesic distance between each pair of latent points is given by the straight line between them
	- $M(z)$ is the pullback metric in the latent space of the VAE induced by the decoder, where $M(z)=\Bbb J_h(\mathbf{z})^\top M(\varphi)\Bbb J_h(\mathbf{z})$
- each cell is an individual probability distribution
- mentions that they plan to extend to do OT-mediated perturbation modeling
