# FlatCFM State Dump — 2026-03-18

## Project Overview

Senior thesis: flow matching on flat latent spaces for single-cell perturbation modeling. Predict heterogeneous single-cell transcriptional responses to drug perturbations in underrepresented contexts. Dataset: sci-Plex3 (~100k cells, 3 cell types: A549, K562, MCF7). K562 is held out for testing. 6396 DEG+HVG genes after feature selection.

Advisor: Smita Krishnaswamy.

## Architecture Pipeline

```
Raw counts (58k genes)
  → Feature selection: HVG (2000) ∪ DEG (top 25 per pert per cell type) = 6396 genes
  → Normalize: log1p(raw_subset / L_total * 10000)  [L_total = sum over ALL genes]
  → Optional: AE encode to latent space (128/512 dims)
  → Flow matching or Neural ODE in latent/gene space
  → Decode back to gene space
  → Evaluate in log1p normalized space
```

## Key Finding: AE Loss–Metric Misalignment

The **central finding** of this thesis work so far:

### The Problem
NB autoencoders destroy perturbation signal in the latent space. Theoretical cosine_logfc limits:
- NB AE d128: ~0.15
- NB AE d256: ~0.15
- NB AE d512: ~0.15 (no improvement with more dims!)
- MSE AE d512: ~0.33
- PCA-50: 0.386

The NB AE with 512 latent dims preserves LESS perturbation signal than 50 linear PCA components.

### Root Cause
NB log-likelihood gradient scales with `x_raw * log(mu)`. High-expression housekeeping genes (100+ counts) generate 100x more gradient than low-expression perturbation-responsive DEGs (0-2 counts). The encoder allocates latent capacity to reproducing the marginal gene distribution, not preserving perturbation-specific variation.

Additionally: `E[log1p(X)] ≠ log1p(E[X])` (Jensen's inequality). The NB decoder outputs mu in count space, but evaluation is in log1p space. The nonlinearity creates a systematic gap.

### Why Per-Gene Mean Can Be Good While cosine_logfc Is Bad
Per-gene mean averages over ALL cells. cosine_logfc measures the DIFFERENCE between perturbed and control group means. The AE can learn to reproduce population-level distributions (good W1, good mean) while losing which specific cells are high/low for each gene — the conditional perturbation structure is compressed away.

### The MSE Fix
MSE AE trains directly in log1p space: `MSE(softplus(decoder(z)), x_input)`. This:
- Treats all genes equally regardless of expression level
- Optimizes in the same space where cosine_logfc is computed
- Forces the encoder to preserve per-cell perturbation-specific information

Downside: MSE decoder produces smooth, dense outputs (Gaussian blob between 0 and expression peak). No zero-inflation, wrong distribution shape. Good cosine_logfc but bad W1.

## Known Issues

### OOM During Training (64GB SLURM allocation)
- DEG computation on 100k cells × 58k genes is memory-heavy
- Feature name caching (`feature_names_{hash}.json`) skips DEG recomputation but NOT HVG
- HVG computation (scanpy `highly_variable_genes` with seurat_v3 flavor) also uses significant memory
- Jupyter kernels (~10GB each) eat into available RAM
- Fix: kill idle kernels before training, or request 128GB allocation
- Workaround: reuse existing pipeline pickle via `ae_export_artifact_tag` pointing to a previously trained experiment

### Feature Name Cache Hash Mismatch
- `_config_hash(cfg["base"])` uses the NORMALIZED config dict, not the raw yaml
- The normalized config includes defaults filled in by `normalize_space_config()`
- Cache file `feature_names_16a8fefce358.json` corresponds to normalized log1p_deg config
- When checking manually, must normalize first: raw yaml hash ≠ normalized hash

### MSE AE Distribution Shape
- MSE decoder outputs smooth, dense values (Gaussian blob)
- No zero-inflation: decoder_mean_zero_frac = 0.0 vs original 0.87
- Good cosine_logfc but bad W1 due to wrong distribution shape
- `reconstruct_counts(sample=True)` for StandardAutoEncoder ignores sample flag — always deterministic

### Softmax Didn't Improve cosine_logfc
- Softmax enforces `sum(mu) = L_subset` (compositional constraint) but NB gradient still scales with raw counts
- Same high-expression gene bias regardless of rate parameterization

### Hybrid NB + MSE Didn't Help Much
- Equal weights (1:1) but NB gradient magnitude dominates since it operates in count space
- The MSE term adds a small correction but doesn't fundamentally change what the encoder learns
- Would need heavy upweighting (e.g., `recon: 0.1, log1p_mse: 1.0`) to shift the balance

## Data Pipeline Details

### Preprocessing Order
1. Gene selection (HVG + DEG) on RAW COUNTS — `fit()` in base transform
2. Subset to selected genes
3. Library size = sum over ALL genes (not just subset)
4. Normalize + log1p: `log1p(raw_subset / L_total * 10000)`

### Two Library Sizes
- `lib_size` in batch = `L_total` (from pipeline transform, sum over all ~58k genes)
- `subset_lib_size` in batch = `L_subset` (sum of raw counts over 6396 subset genes)
- For independent NB: decode uses `L_total` (model compensates with learned rates)
- For softmax NB: decode uses `L_subset` (so `sum(mu) = L_subset` matches raw target)
- For evaluation: always normalize with `L_total` for log1p conversion

### Evaluation Notebook (view_autoencoder_results.ipynb)
- `reconstruct_in_training_space()` computes both `L_total` and `L_subset`
- Checks `inner_model.rate_parameterization` to pick correct decode library size
- `transform_raw()` uses `L_total` for log1p normalization (correct for both parameterizations)

## Flow Matching Details

### Training
- Batches contain randomly sampled perturbed cells from ALL perturbations (not per-perturbation batches)
- Controls randomly sampled from control pool
- OT coupling (Sinkhorn) reassigns control-perturbed pairs within batch
- Condition encoding (perturbation identity, dose, cell type) passed via `cond_batch`

### FM in MSE AE d512 (best model)
- Trained 500 epochs, converged around epoch 300-400
- Val loss plateaus (not overfitting badly)
- Best checkpoint at epoch ~455

## Thesis Direction

### Main Contribution
The AE loss–evaluation metric misalignment: NB AE latent spaces destroy perturbation signal (cos_logfc 0.040 downstream) while MSE AE preserves it (cos_logfc 0.164 downstream). The latent space quality matters more than the generative model itself.

### Results to Highlight
1. FM in MSE AE d512 is best model — competitive with decoder baseline
2. Same FM architecture, 4x improvement just from switching NB→MSE AE
3. MSE AE theoretical limit (0.33) > NB AE (0.15) > PCA explanation
4. Per-gene logfc scatter shows NB learns population mean but loses perturbation structure

### Open Questions
- Can gene-normalized NB get NB-quality distributions with better cosine_logfc?
- Would heavily upweighted log1p_mse (10x) shift the NB encoder enough?
- Does FM in MSE AE d512 beat existing published methods (CPA, GEARS, etc.) on PerturBench?
- Can ODE in MSE AE latent improve over FM? (config created, not yet trained)
